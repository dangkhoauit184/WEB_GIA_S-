# Giao diện mẫu EduCenter ERP

Mở `index.html` trong thư mục này bằng Chrome/Edge/Firefox để xem demo. Nội dung được chuyển nguyên byte từ file index.html gốc, không sửa thiết kế hoặc logic.

Giao diện này dùng localStorage và tài khoản demo, chưa gọi Database/API mới. Khi phát triển, viết code ở `frontend/src/`; không coi mẫu là frontend đang kết nối MySQL.
