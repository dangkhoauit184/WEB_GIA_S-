# Giao diện minh họa EduCenter ERP

Mở [demo/index.html](demo/index.html) trong trình duyệt để xem bản demo gốc. File được chuyển nguyên byte vào `docs/demo/`; không đặt code demo trong khung `frontend/` hoặc `backend/`.

Demo cho phép xem các cổng quản trị viên, giáo vụ, giáo viên, gia sư, trợ giảng và phụ huynh. Dùng nút đăng nhập nhanh hoặc tài khoản mẫu có sẵn trên màn hình.

Dữ liệu và phiên đăng nhập demo được lưu bằng localStorage của trình duyệt. Các thao tác và thông tin API hiển thị trong demo là minh họa, chưa gọi server hay MySQL. Đăng nhập demo không phải xác thực backend. Font trực tuyến có thể dùng font hệ thống thay thế khi không có mạng.

Khung frontend mới ở `frontend/src/modules/` và toàn bộ file HTML/CSS/JS vẫn rỗng. Quy ước phát triển tại [frontend/README.md](../frontend/README.md).
